# ASTRRA TECH — Design System + Navbar + Hero

Premium, original ASTRRA TECH foundation inspired by the visual quality and editorial/cinematic approach of Aspen Search.

## Run

No build tools are required.

```bash
cd astrra-tech
python3 -m http.server 8000
```

Then open:

http://localhost:8000

## Structure

- `index.html` — page structure
- `css/style.css` — design system + responsive UI
- `js/script.js` — navbar behavior, mobile menu, cursor and CTA interaction

## Design system

### Fonts
- Manrope — primary/display type
- DM Mono — labels, navigation and metadata

### Colors
- Deep Black: `#050505`
- Soft Black: `#0D0D0D`
- White: `#F7F7F5`
- Gold: `#C9A227`
- Bright Gold: `#E1BE50`

### Core principles
- Large editorial typography
- Black/white foundation
- Gold as a controlled accent
- Thin borders
- Generous whitespace
- Minimal rounded UI
- Smooth motion
- Strong hover states
- Responsive mobile navigation

The lower sections are intentionally lightweight placeholders so the team can build Services, Work, Process, About and Contact using the same visual language.
